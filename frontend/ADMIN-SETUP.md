# AdaptEd Admin

تم بناء هذه الإضافة على `frontend/final-ui`، نقطة البداية `dd6a852`.
التغييرات تخص Frontend فقط. حساب الأدمن وبياناته تنشئها إدارة الباكند.

## الوصول

1. شغّلي الباكند بقاعدة البيانات وإعدادات الفريق المعتادة.
2. من مجلد `frontend` شغّلي `npm install` ثم `npm run dev`.
3. افتحي `/login` وسجّلي الدخول بحساب حقيقي دوره `admin`.
4. ينتقل الحساب تلقائيًا إلى `/admin/dashboard`.

يمكن فتح `/admin/users` أو `/admin/lessons` مباشرة. المستخدم غير المسجّل ينتقل إلى تسجيل الدخول ثم يعود إلى الصفحة المطلوبة إذا كان أدمن. الطالب والمعلم تظهر لهما رسالة أن الدخول مخصص للأدمن، مع رابط العودة إلى حسابهما.

لا يوجد خيار Admin في التسجيل العام، ولا حساب تجريبي أو كلمة مرور مضمّنة في الفرونت. يلزم الحصول على بيانات حساب الأدمن من مسؤولة الباكند.

الإعداد الافتراضي للـAPI هو `http://localhost:5000/api`.
عند استخدام عنوان مختلف، ضعي في `frontend/.env.local` الإعدادات المناسبة ثم أعيدي تشغيل Vite:

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_DEMO_MODE=false
VITE_TEST_MODE=false
```

## الصفحات والربط

- Dashboard: خمس إحصائيات، توزيع المستخدمين، وأحدث خمسة دروس من ردود السيرفر.
- Users: الاسم والإيميل والدور. البحث والفلترة في السيرفر، وتقسيم النتائج محليًا إلى 12 صفًا في الصفحة.
- Lessons: عنوان الدرس، صاحبه، نوع الملف وتاريخ الإنشاء. البحث في السيرفر، وفلتر نوع الملف وتقسيم النتائج محليًا.

كل الطلبات تستخدم Axios client الحالي ونفس Authorization token.

| API | الاستجابة المستخدمة |
| --- | --- |
| GET /api/admin/stats | stats.totalUsers, totalStudents, totalTeachers, totalLessons, totalAIGenerations |
| GET /api/admin/users?search=&role= | users: [{id, name, email, role, created_at}] |
| GET /api/admin/lessons?search= | lessons: [{id, title, owner_name, owner_email, file_type, original_name, created_at}] |

القيم المتوقعة لـfile_type هي PDF وVideo وOther، كما يرجعها adminController الحالي.
إحصائيات AI تعرض عدد السجلات التي يرجعها السيرفر، ولا تمثّل عدد المستخدمين النشطين أو نسبة نمو.

طلبات البحث المتأخرة تُلغى عند تغيير البحث أو الانتقال إلى صفحة أخرى. لا يتم تعويض فشل الطلب ببيانات تجريبية أو أرقام صفرية. تظهر حالة تحميل، ثم البيانات أو حالة فارغة أو رسالة خطأ مع إعادة المحاولة. انتهاء الجلسة يعرض رابط تسجيل الدخول، وعدم الصلاحية يعرض رسالة واضحة.

مسارات الواجهة تُحجب حسب الدور، وحماية البيانات الفعلية مسؤولية authMiddleware وadminMiddleware الموجودين بالباكند.

## التحقق

نجح ESLint وVite build.
تم اختبار الدخول حسب الدور، حماية صفحات الأدمن من الطالب والمعلم، الرجوع إلى الصفحة المطلوبة بعد الدخول، البحث والفلاتر وتقسيم الصفحات، إلغاء الطلبات المتأخرة، البيانات الفارغة وغير الصالحة، أخطاء 401 و403 و500 وإعادة المحاولة، تسجيل الخروج، العرض العربي وقائمة الموبايل وتمرير الجداول.

اختبارات المتصفح استخدمت ردود API مضبوطة مطابقة لكود الباكند في النسخة المسحوبة، ولم تتصل بقاعدة بيانات الفريق. تبقى تجربة الحساب الحقيقي على بيئة الفريق خطوة التحقق النهائية.

## النشر

الإضافة لا تغيّر نظام التسجيل إلى طلبات المعلمين، ولا تضيف حذف الدروس أو تعديل أدوار المستخدمين.
نسخة الإنتاج تستخدم نفس طريقة النشر الحالية، ويجب توجيه مسارات `/admin/*` إلى `index.html` مثل بقية مسارات React Router.
